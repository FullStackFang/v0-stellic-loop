# Local EMBA rehearsal

The synthetic fixture creates an EMBA root with Vietnam and Estonia child loops, eight member opt-ins, a separate organizer and a nonmember. It uses fixed 2099 itinerary/activity dates, fixed identity and operation IDs, and an ephemeral Ed25519 key held only in the fixture process. The signed update is labeled service-attested. Its key is not a production credential or custody model.

The Hanoi itinerary is a versioned JSON source with a 14:00 bus passage, `/passages/0` citation, source URL, and `Asia/Ho_Chi_Minh` timezone. Member A has two private Hanoi afternoon items. Member B's planning context has no access to A's wants. The two opt-ins requiring eight *other* people fail the fixed-point resolution; six survive. Closing the activity freezes an organizer report of `{ "suppressed": true }`, so the eight/six complement is not published in the organizer view.

`lib/__tests__/emba-rehearsal.test.ts` passed locally on 2026-11-06. It exercised the registered MCP server with the SDK client and in-memory transport: tool/resource discovery, resource read, cited planning, denied unleased Estonia planning, exact first-party commitment confirmation, changed-payload rejection, one-time execution, and a denied read on the same connection after scoped lease revocation. A separate nonmember MCP client was denied both source search and planning. It also checked nonmember source denial through the knowledge service and verified the signed update. TypeScript `tsc --noEmit` and changed-file ESLint passed.

The standalone command is `npm run emba:rehearsal` (equivalent to `node --conditions=react-server --import tsx scripts/emba-rehearsal.ts`). It explicitly rejects `QB_DB=remote` before opening `openTestDb()`. The command passed locally when rerun outside the restrictive sandbox; the earlier sandboxed launch failed before script code ran because Node's `os.userInfo()` returned `uv_os_get_passwd ENOMEM`. No remote database, OAuth, browser connector, or real user account was exercised. Portal browser flows and alternate legacy-route denial remain separate acceptance work.
