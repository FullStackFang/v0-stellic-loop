Loop · Advisor · Dana · v4

B3 cards, with three sub-tab dials

The body is B3 as picked. Only the row under the header changes. Each dial is a control the app already uses somewhere, so whichever you pick, Dana's tabs will look like something she has tapped before.

D1 · segmented

A track and a thumb

The app's segmented control: a sunken track, a raised thumb that slides to the tab you are on. The count sits under the label, so three cells share the width evenly without truncating. Reads as "one of three views".

try: tap Check on, then Pulse
D2 · chips

The Home row

Three raised pills, the same ones as Your week · Waiting · Past on Home. The one you are on is accent-quiet with the glow, which the app already uses for "this is yours / this is on". Reads as "three lists".

try: tap Route, then Pulse
D3 · tab strip

Equal cells, count as a badge

The underline dial tidied: three equal cells so the underline is a fixed width, and the count moves into a badge. Accent-quiet when it is something to do (4 people, 3 spots), plain when it is a reading (66%). Reads as "tabs".

try: tap Check on, then Route
